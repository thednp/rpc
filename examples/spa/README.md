# SPA Example

Single-Page Application using Vite dev server with `@thednp/rpc` for automatic RPC generation. No SSR — client-side only with a dedicated RPC proxy server.

## Scripts

| Command | Description |
|---------|-------------|
| `pnpm dev` | Start Vite dev server |
| `pnpm build` | Type-check and build for production |
| `pnpm preview` | Build and preview production build |
| `pnpm start` | Preview production build |

## Dependencies

- `vite` — Dev server and build tool
- `valibot` — Runtime validation
