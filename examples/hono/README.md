# Hono Example

Server-Side Rendering (SSR) application using Hono with `@thednp/rpc` for automatic RPC generation.

## Scripts

| Command | Description |
|---------|-------------|
| `pnpm dev` | Start development server with Vite HMR |
| `pnpm build` | Build client and server for production |
| `pnpm preview` | Build and start production server |
| `pnpm start` | Start production server |

## Dependencies

- `hono` — HTTP server framework
- `@hono/node-server` — Node.js adapter for Hono
- `@hono/vite-dev-server` — Vite dev server integration
- `valibot` — Runtime validation
- `vite` — Dev server and build tool
